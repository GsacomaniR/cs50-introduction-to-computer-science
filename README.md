# CS50 – Introduction to Computer Science (Harvard)

Este repositório contém meus estudos, exercícios e projetos desenvolvidos ao longo do curso **CS50 – Introduction to Computer Science**, da Universidade de Harvard.

O objetivo é documentar minha evolução em **lógica de programação**, **algoritmos** e **fundamentos da ciência da computação**, utilizando diferentes linguagens e tecnologias.

---

##  Estrutura do Repositório

O conteúdo está organizado por módulos, seguindo a estrutura do curso:

- **Linguagem C**
- **Arrays**
- **Algoritmos**
- **Memória**
- **Estruturas de Dados**
- **Python**
- **Inteligência Artificial**
- **SQL**
- **HTML, CSS e JavaScript**
- **Flask**
- **Ética**

Cada módulo possui seus próprios arquivos e, quando necessário, um README específico com explicações.

---

##  Objetivos de Aprendizado

- Desenvolver raciocínio lógico e pensamento computacional
- Compreender como programas funcionam em baixo nível
- Aprender fundamentos de algoritmos e estruturas de dados
- Consolidar boas práticas de programação
- Criar uma base sólida para projetos mais complexos

---

##  Tecnologias Utilizadas

Ao longo do curso, são trabalhadas as seguintes tecnologias:

- Linguagem C
- Python
- SQL
- HTML, CSS e JavaScript
- Flask
- Git e GitHub
