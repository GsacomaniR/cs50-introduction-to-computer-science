# Linguagem C – Fundamentos (CS50)

Este diretório contém os exercícios desenvolvidos durante o módulo de **Linguagem C** do curso **CS50 – Introduction to Computer Science (Harvard)**.

O objetivo deste módulo foi compreender os fundamentos da programação estruturada e desenvolver o raciocínio lógico utilizando a linguagem C.

---

##  Conteúdos Trabalhados

- Variáveis e tipos de dados
- Estruturas condicionais (`if`, `else`)
- Laços de repetição (`for`, `while`)
- Entrada e saída padrão
- Compilação com `clang`
- Organização básica de código

---

##  Exercícios

- **mario.c**  
  Construção de padrões utilizando laços de repetição.

- **cash.c**  
  Cálculo de troco com base em lógica condicional e divisão por moedas.

- **credit.c**  
  Validação de números de cartão utilizando o **algoritmo de Luhn**.
  
- **population.c**
  
  Simulação do crescimento populacional ao longo dos anos, utilizando laços de repetição, validação de entradas e controle de variáveis para representar o aumento e diminuição da população conforme regras definidas.
  
---

##  Aprendizados

Este módulo foi essencial para:
- Fortalecer a lógica de programação
- Entender como o código é executado em baixo nível
- Desenvolver atenção a detalhes como tipos de dados e controle de fluxo
- Criar uma base sólida para algoritmos e estruturas de dados

---

##  Observação

Os exercícios foram desenvolvidos para fins educacionais, seguindo as propostas do curso CS50.
