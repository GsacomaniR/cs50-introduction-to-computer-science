CC50 - Projetos Extras e Exercícios
Este repositório contém projetos extras e exercícios práticos desenvolvidos durante o curso CC50 (Ciência da Computação de Harvard), adaptado para português. Aqui você encontrará implementações em C para fixar os conceitos fundamentais da computação.

Estrutura dos Arquivos
**Exercícios de Introdução à C**
hello.c - Primeiro programa em C ("Hello, World!")

hi.c - Variação do programa de saudação

uppercase.c - Converte texto para maiúsculas

**Manipulação de Dados e Strings**
scores.c - Trabalhando com arrays e notas

string.c - Implementação de funções para manipulação de strings

argv.c - Trabalhando com argumentos da linha de comando

**Depuração e Controle**
buggy0.c - Programa com bugs para prática de debug

buggy1.c - Outro exemplo para exercitar depuração

exit.c - Demonstração de códigos de saída e controle de fluxo

**Como Compilar e Executar**
Compilação Básica
bash
# Compilar um programa
gcc -o hello hello.c

# Executar
./hello
Compilação com Depuração
bash
# Compilar com símbolos de debug
gcc -g -o buggy0 buggy0.c

# Usar GDB para depurar
gdb ./buggy0
Compilação com Todos os Avisos
bash
# Compilar com warnings ativados
gcc -Wall -Wextra -o programa arquivo.c
